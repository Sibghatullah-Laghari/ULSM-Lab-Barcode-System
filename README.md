# ULSM Lab Barcode Management Utility

A lightweight Java application for creating, decoding, and managing laboratory sample barcodes. The utility is designed to improve sample tracking while helping laboratories maintain organized digital records.

## Overview

This project offers a simple framework for barcode processing in laboratory environments. It allows users to:

* Create barcode values from laboratory sample information.
* Decode barcode values into readable sample details.
* Maintain sample records in memory during application execution.
* Verify input before barcode generation or decoding.

## Main Features

* URL-safe Base64 encoding and decoding.
* Validation of patient IDs, sample IDs, and laboratory test codes.
* In-memory repository for temporary sample record storage.
* Simple command-line interface for demonstrations and testing.
* Maven project with JUnit 5 unit testing support.

## Technology Stack

* Java 17
* Apache Maven 3.9+
* JUnit 5

## Requirements

Before running the application, ensure the following software is installed:

* Java Development Kit (JDK) 17
* Apache Maven 3.9 or newer

## Build and Test

Clone the repository and run:

```bash
mvn test
```

This command compiles the project and runs all available unit tests.

## Package the Application

Create the application package using:

```bash
mvn -q package
```

## Generate a Barcode

Execute:

```bash
java -cp target/classes com.ulsm.lab.barcode.App encode P-1001 CBC S-22001
```

Example output:

```text
UC0xMDAxfENCQ3xTLTIyMDAx
```

## Decode a Barcode

Execute:

```bash
java -cp target/classes com.ulsm.lab.barcode.App decode UC0xMDAxfENCQ3xTLTIyMDAx
```

Example output:

```text
patientId=P-1001, testCode=CBC, sampleId=S-22001
```

## Processing Workflow

1. Enter the patient ID, test code, and sample ID.
2. The application validates the supplied information.
3. A pipe-separated data string is prepared.
4. The data is encoded using URL-safe Base64.
5. When decoding, the original sample information is reconstructed.
6. Sample records may be stored temporarily within the in-memory repository.

## Troubleshooting

### Maven Not Available

Error:

```text
mvn: command not found
```

Solution:

Install Apache Maven and ensure it is available in your system PATH.

### Unsupported Java Version

Error:

```text
invalid target release: 17
```

Solution:

Verify that JDK 17 is installed and configured as the active Java version.

### Barcode Cannot Be Decoded

Possible cause:

The barcode value may have been modified or was not generated by this application.

### Command-Line Execution Issues

Ensure the command syntax is correct.

Encoding format:

```text
encode <patientId> <testCode> <sampleId>
```

Decoding format:

```text
decode <barcodeValue>
```
