# ULSM-Lab-Barcode-System

Java-based lab barcode utility for encoding/decoding sample metadata and managing sample records safely.

## Project Overview

This project provides a small, maintainable Java baseline for lab barcode workflows:

- Create a barcode payload from patient/test/sample identifiers.
- Decode barcode payloads back into structured data.
- Keep sample records in an in-memory repository.
- Validate input early to reduce malformed data issues.

## Features

- URL-safe Base64 barcode payload encoding/decoding.
- Strong input validation for patient ID, test code, sample ID, and barcode text.
- In-memory sample record storage by sample ID.
- Minimal CLI entry point for quick smoke usage.
- Maven + JUnit test scaffolding for safe future changes.

## Tech Stack / Dependencies

- Java 17
- Maven 3.9+
- JUnit 5 (tests)

## Setup

1. Install JDK 17.
2. Install Maven 3.9 or later.
3. Clone the repository.
4. From project root, run:

```bash
mvn test
```

## How to Run (CLI)

From project root:

```bash
mvn -q compile exec:java -Dexec.mainClass="com.ulsm.lab.barcode.App" -Dexec.args="encode P-1001 CBC S-22001"
```

or directly with Java after compile:

```bash
mvn -q package
java -cp target/classes com.ulsm.lab.barcode.App encode P-1001 CBC S-22001
java -cp target/classes com.ulsm.lab.barcode.App decode <BARCODE_VALUE>
```

## Generate and Decode Barcode (Example)

### Encode

```bash
java -cp target/classes com.ulsm.lab.barcode.App encode P-1001 CBC S-22001
```

Example output:

```text
UC0xMDAxfENCQ3xTLTIyMDAx
```

### Decode

```bash
java -cp target/classes com.ulsm.lab.barcode.App decode UC0xMDAxfENCQ3xTLTIyMDAx
```

Example output:

```text
patientId=P-1001, testCode=CBC, sampleId=S-22001
```

## Data Flow Summary

1. User provides `patientId`, `testCode`, `sampleId`.
2. `LabSampleRecord` validates and stores the normalized values.
3. `BarcodeCodec.encode(...)` serializes fields (`patientId|testCode|sampleId`) and Base64-url encodes payload.
4. `BarcodeCodec.decode(...)` validates input, decodes payload, reconstructs `LabSampleRecord`.
5. `InMemorySampleRecordRepository` stores/fetches records by `sampleId`.

## Troubleshooting

- **`mvn: command not found`**
  - Install Maven and ensure it is on `PATH`.
- **`invalid target release: 17`**
  - Ensure JDK 17 is installed and active (`java -version`).
- **Decode throws invalid barcode error**
  - Confirm the barcode value is URL-safe Base64 generated by this app.
- **No output from CLI**
  - Re-check command arguments:
    - `encode <patientId> <testCode> <sampleId>`
    - `decode <barcodeValue>`
